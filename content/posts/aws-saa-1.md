AWS SAA는 **AWS 서비스를 조합해 요구사항에 맞는 시스템을 설계하는 능력**을 평가하는 자격증이다. 서버, 네트워크, 저장소, 데이터베이스를 함께 공부하기 때문에 AWS 전반의 기초를 잡는 학습 목표로 삼을 만하다.

이번 시리즈에서는 SAA 취득을 목표로 개념과 서비스 선택 기준을 정리한다. 1편에서는 **어떤 시험인지, 무엇이 어려운지, 어떻게 공부할지**부터 살펴본다.

## 1. AWS SAA는 어떤 자격증인가

정식 명칭은 **AWS Certified Solutions Architect – Associate**다. 여기서 아키텍처는 시스템을 구성하는 요소와 그 연결 구조를 뜻한다.

쇼핑몰을 만든다고 생각해보자. 서버와 데이터베이스를 준비한 뒤에도 결정해야 할 일이 남는다.

- **사용자가 몰리면?** 처리 용량을 늘리고 요청을 분산해야 한다.
- **장애가 발생하면?** 서비스를 유지하거나 필요한 상태로 복구해야 한다.
- **고객 정보를 저장한다면?** 접근 권한과 데이터 보호 방법을 정해야 한다.
- **비용이 너무 크다면?** 필요한 성능을 유지하면서 구성을 조정해야 한다.

SAA에서는 이런 조건에 맞는 AWS 서비스와 구성을 선택한다. 공부할 때도 서비스 이름에 이어 **“왜 이 상황에서 사용하는가”**까지 이해해야 한다. [공식 시험 가이드](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-associate-03/solutions-architect-associate-03.html)

개발자에게는 코드가 실행되는 인프라를, 데이터 엔지니어에게는 데이터 처리 주변의 네트워크와 권한을 이해하는 계기가 된다. 자격증 공부로 익힌 기준을 실습에 적용하면 서비스들이 연결되는 모습도 구체적으로 볼 수 있다.

## 2. 시험 정보 한눈에 보기

**2026년 11월 16일 확인한 공식 안내 기준**이다.

| 항목 | 내용 |
| --- | --- |
| 시험 코드 · 등급 | **SAA-C03 · Associate** |
| 문제 수 · 시간 | **65문항 · 130분** |
| 문제 유형 | 단일 선택형 / 복수 선택형 |
| 합격 기준 | 환산 점수 100~1,000점 중 **720점 이상** |
| 기본 응시료 | **150 USD** — 결제 통화·세금에 따라 실제 금액 확인 필요 |
| 언어 · 응시 장소 | 한국어 지원 · 시험 센터 또는 온라인 감독 시험 |
| 유효기간 | 3년 |

65문항은 채점 문항 50개와 비채점 문항 15개로 구성되며, 시험 중에는 구분되지 않는다. **720점은 정답률 72%라는 뜻이 아니다.** 시험별 난이도 차이를 반영한 환산 점수다. [시험 안내](https://aws.amazon.com/certification/certified-solutions-architect-associate/), [채점 방식](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-associate-03/solutions-architect-associate-03.html)

## 3. 난이도: 넓은 범위와 서비스 비교가 관건

**IT 기초가 있다면 AWS의 설계 방식을 익히는 과정이고, IT 자체가 처음이라면 기초 개념부터 함께 공부해야 하는 시험**으로 접근하면 좋다.

AWS는 약 1년 이상의 AWS 클라우드 솔루션 설계 경험을 권장한다. 깊이 있는 코딩 경험은 요구하지 않는다. [권장 경험](https://aws.amazon.com/certification/certified-solutions-architect-associate/)

자신의 출발점에 따라 학습 비중을 달리 잡을 수 있다. 아래는 공부 방향을 위한 제안이다.

| 현재 상태 | 먼저 집중할 부분 |
| --- | --- |
| IT와 클라우드가 모두 처음 | 서버, IP, DNS, 데이터베이스 등 기초 용어 |
| 개발 경험은 있지만 AWS는 처음 | 익숙한 구성 요소와 AWS 서비스의 역할 연결 |
| 일부 AWS 서비스를 사용해봄 | 평소 쓰지 않던 영역과 유사 서비스의 차이 |

공부하면서 막히기 쉬운 부분은 **여러 선택지가 모두 가능해 보이는 상황**이다. 작동하는 구성이라도 비용, 장애 대응, 운영 부담을 따져보면 적합성이 달라진다. 문제에서 반드시 만족해야 할 조건과 가장 우선하는 목표를 구분하는 연습이 필요하다.

## 4. 무엇을 공부하나: 네 가지 설계 영역

시험은 **보안·복원력·성능·비용**이라는 네 관점에서 설계를 평가한다.

![AWS SAA 출제 비중: 보안 아키텍처 설계 30%, 복원력 26%, 고성능 24%, 비용 최적화 20%](/images/aws-saa-1/exam-domain-weights.svg)

| 영역 | 주요 학습 내용 |
| --- | --- |
| 보안 | 접근 권한, 암호화, 네트워크 보호 |
| 복원력 | 고가용성, 장애 대응, 백업과 복구 |
| 고성능 | 컴퓨팅·스토리지·데이터베이스의 선택과 확장 |
| 비용 최적화 | 요구사항을 만족하는 자원과 요금 방식 선택 |

그림은 공식 시험 영역의 비중을 바탕으로 작성했다. 개별 서비스의 출제 비율을 뜻하지는 않는다. [공식 출제 영역](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-associate-03/solutions-architect-associate-03.html)

## 5. 공부 방법: 개념 → 비교·실습 → 문제 풀이

처음부터 모든 기능을 외우려고 하면 진도가 잘 나가지 않는다. **서비스의 역할을 먼저 익히고, 차이를 비교한 뒤, 문제에 적용하는 순서**로 진행하려고 한다.

### ① 개념: 서비스가 맡는 역할부터

첫 회독에서는 “이 서비스가 어떤 문제를 해결하는가”를 한두 문장으로 정리한다. 이번 시리즈도 다음 흐름으로 기본기를 쌓을 예정이다.

| 단계 | 학습 주제 |
| --- | --- |
| 기초 | 리전·가용 영역·공동 책임 모델 → IAM과 접근 권한 → VPC와 네트워크 |
| 주요 서비스 | 컴퓨팅 → 스토리지 → 데이터베이스 |
| 서비스 연결과 운영 | 서버리스·메시징 → 모니터링·재해 복구·비용 최적화 |

이 순서는 학습을 위한 구성이다. 세부 범위는 공식 시험 가이드와 함께 확인한다.

### ② 비교·실습: 어떤 조건에서 선택할지

비슷한 서비스를 나란히 놓고 **사용 목적, 차이, 선택 조건**을 정리한다. 작은 실습으로 설정과 결과를 연결해보면 설명만 읽을 때 놓친 부분이 드러난다.

실습 하나에서 확인할 질문도 작게 잡는다. 예를 들어 “접근 권한을 바꾸면 요청 결과가 어떻게 달라지는가?”를 확인하고, 요청을 보내는 주체와 대상 리소스의 관계를 그려보는 식이다.

### ③ 문제 풀이: 정답을 고른 이유까지

오답 노트에는 해설 전체를 옮기기보다 세 가지만 남긴다.

- **놓친 조건:** 문제에서 반드시 만족해야 했던 요구사항
- **선택 근거:** 정답이 그 조건을 충족하는 이유
- **비교 기준:** 내가 고른 답이 적합하지 않은 이유

맞힌 문제도 이유를 설명하지 못했다면 다시 본다. AWS 공식 준비 과정에서도 연습문제와 지식 보완, 실습, 준비도 평가를 함께 활용한다. [공식 시험 준비 자료](https://aws.amazon.com/certification/certified-solutions-architect-associate/)

## 6. 준비 기간과 다음 편

준비 기간은 현재 지식과 공부 가능한 시간에 맞춰 잡자. 우선 일주일 정도 기초를 공부한 뒤, 이해에 걸리는 시간을 기준으로 나머지 일정을 조정하는 방법을 권한다. 특정 주차를 채우는 것보다 **처음 보는 문제에서 요구사항을 찾고 선택 이유를 설명할 수 있는지**를 확인하는 편이 낫다.

다음 편에서는 **리전, 가용 영역, 공동 책임 모델**을 다룬다. AWS 인프라가 어떻게 나뉘어 있고 사용자가 무엇을 책임지는지부터 알아보자.
