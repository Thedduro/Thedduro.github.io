데이터 파이프라인은 단순히 데이터를 옮기는 코드가 아닙니다. 신뢰성, 확장성, 관측 가능성 그리고 실제 비즈니스 요구가 함께 맞물려야 오래 살아남는 시스템이 됩니다.

이 블로그에는 그 시스템을 설계하고 운영하며 알게 된 내용과 문제를 해결한 과정을 기록하려고 합니다. 단순한 결과보다 **왜 그렇게 판단했는지**를 남기는 것이 목표입니다.

## 이 블로그에서 다룰 내용

- Kafka와 Flink를 활용한 실시간 스트리밍
- Spark 기반 대규모 배치 처리와 Airflow 워크플로
- 데이터 플랫폼을 지탱하는 백엔드와 클라우드 인프라
- 데이터 파이프라인과 연결되는 AI·LLM 애플리케이션

## 코드 작성 예시

코드 블록은 언어를 지정하면 문법 강조와 줄 번호가 적용됩니다.

```go
package main

import "fmt"

func main() {
    fmt.Println("Data should keep flowing.")
}
```
